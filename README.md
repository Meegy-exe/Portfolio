## Meow City *(En développement)*
> **Jeu de gestion de colonie incrémental (idle game) isométrique.**
* ![Discord](https://img.shields.io/badge/Discord-5865F2?style=for-the-badge&logo=discord&logoColor=white) ![Node.js](https://img.shields.io/badge/Node.js-339933?style=for-the-badge&logo=node.js&logoColor=white) ![Excalidraw](https://img.shields.io/badge/Excalidraw-6965DB?style=for-the-badge&logo=excalidraw&logoColor=white)
* **L'Équipe :** Développé en collaboration (Co-Developer & Game Designer : Meegy-exe & Maximo4).
* **Idée :** Aidez vos félins à bâtir la civilisation la plus paresseuse, mais la plus efficace de l'histoire, en vénérant un Dieu Chat.

* **Gameplay :**
  * **Le Grattoir Ancestral (Clicker) :** Intégration d'un système de clicker inspiré de *Cookie Clicker*. Cliquer pour "gratter" le monument central génère de l'herbe à chat, la ressource important du jeu.

## Installation en local
Pour faire tourner ce projet sur votre propre machine :

```bash
# Cloner le repository
git clone [https://github.com/ton-pseudo/ton-repo.git](https://github.com/ton-pseudo/ton-repo.git)

# Aller dans le dossier du projet
cd ton-repo

# Installer les dépendances
npm install

# Lancer le serveur de développement local
npm run dev
